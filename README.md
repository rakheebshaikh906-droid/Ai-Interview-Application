# AI Interview Prep

A modern interview preparation web application built using HTML, CSS, and JavaScript.

This project helps users practice technical interview questions with different categories and difficulty levels in a clean and interactive interface.

---

## Features

- Category-based interview questions
- Difficulty levels (Easy, Medium, Hard)
- Timer countdown system
- Progress bar
- Score tracking
- Voice reading using SpeechSynthesis API
- Randomized questions
- Modern responsive UI

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
